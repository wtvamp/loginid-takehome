When `exit_on_err` is set to true, Vault Agent and Vault Proxy will exit if any errors occur during authentication.

However, this doesn't mean it exits immediately on the first auth failure. Instead, if the authentication request fails, the tool retries the request with an exponential back off. The retry behavior is controlled by the `min_backoff` and `max_backoff` parameters, where the maximum time Agent will delay before retrying after a failed auth attempt is controlled by max_backoff, and the backoff will start at min_backoff and double (with some randomness) after successive failures, capped by max_backoff.

So to summarize: **`exit_on_err` does not exit on the first auth failure immediately. Instead, Vault Agent will retry authentication with exponential backoff. If an error occurs during an authentication attempt, `exit_on_err` determines whether to exit after those retries are exhausted or continue retrying indefinitely.**
