278	// may proceed now for THIS specific kid, and if so atomically marks one
279	// as just having started. Keyed per kid, not by one global timestamp
280	// (Ingrid Solano, 02 cold re-check): KeyForKid runs before signature
281	// verification, so an unauthenticated caller can send a token with a
282	// fabricated kid at no cost — a single global gate lets that caller
283	// permanently occupy the one reservation slot by repeating it every
284	// jwksUnknownKidRefetchInterval, pushing a legitimately-rotated real
285	// key's own refetch back to the full calendar-TTL rollover, silently
286	// recreating most of the original gap this mechanism exists to close.
287	// Per-kid closes that: a garbage kid's repeated reservation never blocks
288	// a DIFFERENT (real) kid's own reservation. jwksMaxTrackedUnknownKids
289	// caps how many distinct kids can hold a reservation at once, so a flood
290	// of distinct fabricated kids still can't hammer the issuer past that
291	// bound — rate-limiting is scoped per-kid, not removed.
292	func (c *JWKSCache) reserveUnknownKidRetry(kid string) bool {
293		c.mu.Lock()

281	// verification, so an unauthenticated caller can send a token with a
282	// fabricated kid at no cost — a single global gate lets that caller
283	// permanently occupy the one reservation slot by repeating it every
284	// jwksUnknownKidRefetchInterval, pushing a legitimately-rotated real
285	// key's own refetch back to the full calendar-TTL rollover, silently
286	// recreating most of the original gap this mechanism exists to close.
287	// Per-kid closes that: a garbage kid's repeated reservation never blocks
288	// a DIFFERENT (real) kid's own reservation. jwksMaxTrackedUnknownKids
289	// caps how many distinct kids can hold a reservation at once, so a flood
290	// of distinct fabricated kids still can't hammer the issuer past that
291	// bound — rate-limiting is scoped per-kid, not removed.

309			}

313			// one rather than let the map grow further. The ordinary
314			// TTL-driven refresh still eventually picks up a real rotated

360	// network attempt because jwksMinRefreshRetryInterval hasn't elapsed yet
361	// (Oren Castellan, PR #30 re-review: without this, backing off from
362	// hammering a struggling issuer would also silently suspend the
363	// staleness ceiling for however long the backoff lasts).
