LoginID take-home — live API demo

This page lets you drive the actual identity API live from your browser, so you can watch its access rules and safeguards work in real time instead of taking our word for it.

● Get a token

You paste a temporary QA test login here only to get a real access token for this demo — it stays in this browser tab, is never saved anywhere, and is only ever used to talk to this one page's own login endpoint.

1 Masked search vs. full read

This shows the same person's record returned two different ways depending on what the caller is allowed to see — one version hides sensitive fields, the other reveals them — proving access is limited to what each caller has earned, not an all-or-nothing switch.

Needs a profile:search token and a profile:read:any token minted above.

2 The two 403s

This shows that being denied for "you don't have permission" and being denied because "that record doesn't exist" look exactly, byte-for-byte, the same from the outside, so no one can use the error message to go fishing for which accounts are real.

Needs a profile:read:own token minted above. Uses two fresh, unpredictable record ids this credential was never granted — one may exist, one almost certainly doesn't; neither matters to the result.

5 The rate limit tripping

This shows the API cutting off a rapid burst of real requests in real time, proving it can defend itself against being hammered rather than just claiming to.

Runs last on purpose: the limit is shared by every visitor currently using the same seeded QA credential, so tripping it here really does affect anyone else driving this panel in the same window — not a per-visitor sandbox.
